# Week 01 - PM4: Wireshark Project

## Overview
Completed the Networkwalks Wireshark Project, involving five practical labs focused on packet analysis, network traffic investigation, and identifying security-related information.

## Tools Used
- Wireshark
- Google Chrome
- Windows Command Prompt
- Networkwalks Wireshark SOC Labs
- PCAP sample file

## Practical Labs

### Lab 1: Follow TCP Stream
- Captured and analysed web traffic.
- Used Follow TCP Stream to investigate a hidden note.

### Lab 2: Catch the Call Scammer
- Investigated VoIP traffic.
- Analysed a captured call and answered questions about the conversation.

### Lab 3: HTTP Plain Text Credentials
- Examined HTTP traffic.
- Identified login information transmitted without encryption in the provided lab capture.

### Lab 4: Capture Packets on Your Network & PC
- Captured network traffic using Wireshark.
- Investigated DNS queries and responses.
- Identified IP addresses, TLS Server Name Indication (SNI), server port, and TLS version.

### Lab 5: Analyse a PCAP File
- Opened and analysed the provided Microsoft DNS PCAP file.
- Examined DNS queries and responses.
- Identified IP addresses and analysed TLS Client Hello and Server Hello packets.

## Learning Outcomes
- Understood packet capture and network traffic analysis.
- Practised using Wireshark display filters.
- Learned to inspect TCP streams, DNS traffic, HTTP traffic, and TLS handshakes.
- Improved practical troubleshooting and packet investigation skills.
