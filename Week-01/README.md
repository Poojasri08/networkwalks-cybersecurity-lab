# Week 01 – Cybersecurity Internship

## Overview

This folder documents the practical lab setup and activities completed during Week 1 of my Cybersecurity Internship at Networkwalks.

## Activities Completed

- Installed Kali Linux using Oracle VirtualBox.
- Configured a NAT Network named `NatNetwork`.
- Assigned a static IP address (`10.0.0.2`) to the Kali Linux machine.
- Configured a shared folder between the host and virtual machine.
- Created a virtual machine snapshot.

## Learning Outcomes

- Gained experience setting up a Linux-based cybersecurity lab.
- Learned basic virtual network configuration.
- Practised static IP configuration.
- Understood shared-folder setup and VM snapshots.
