# PM2 – Password Cracking with Networkwalks Tools

## Objective
To extract a PDF password hash and recover the password using Networkwalks online tools.

## Tools Used
- Networkwalks Hash Calculator
- Networkwalks Password Cracker

## Procedure
1. Downloaded the PM2 lab PDF: `My Locked PDF1 (for NW Tools Lab WK3-PM2)(1).pdf`.
2. Uploaded the PDF to the Networkwalks Hash Calculator.
3. Selected the PDF tab to extract the PDF hash.
4. Copied the generated `$pdf$` hash.
5. Opened the Networkwalks Password Cracker.
6. Used the available wordlist to perform the password-cracking attempt.
7. Successfully recovered the PDF password.
8. Entered the recovered password and verified that the PDF opened.

## Result
**Status:** Successfully completed.

The locked PM2 PDF was successfully unlocked.
