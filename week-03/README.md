# Week 03 – Password Cracking

## Overview
This week focused on password cracking using John the Ripper and Networkwalks password-cracking tools.

## PM1 – Password Cracking with John the Ripper

**Tool used:** John the Ripper (Jumbo 1.9.0)

**Steps completed:**
1. Installed and configured John the Ripper and Johnny.
2. Installed Strawberry Perl.
3. Used `pdf2john.pl` to extract the PDF password hash.
4. Loaded the hash into Johnny.
5. Successfully recovered the PDF password.
6. Verified the password by opening the locked PDF.

**Recovered password:** `good-luck`

**Evidence:** `Evidence/PM1-JTR/`

## PM2 – Password Cracking with Networkwalks Tools

**Tools used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker

**Steps completed:**
1. Uploaded the PM2 PDF to the Hash Calculator.
2. Selected the PDF hash format.
3. Extracted the PDF hash.
4. Used the Networkwalks Password Cracker.
5. Successfully recovered the password.
6. Verified that the locked PDF opened.

**Evidence:** `Evidence/PM2-Networkwalks-Tools/`

## Learning Outcomes
- Understood PDF password hash extraction.
- Practised password cracking using John the Ripper.
- Worked with Johnny GUI.
- Used online password-cracking tools.
- Understood the importance of password security.
